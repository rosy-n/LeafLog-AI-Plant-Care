# 식물 등록 중 이탈 및 복귀 확인

## 동작 범위

- 생성 요청이 서버에 접수된 뒤부터 등록 내용을 기기에 보관한다.
- 종 선택, 상세정보 입력, 후보 선택, 이름 입력 중 상단 X로 저장하고 나갈 수 있다.
- 일반 뒤로가기로 등록 화면을 닫아도 접수된 작업은 보관한다.
- 정원 마지막 카드와 하단 진행 알림에서 미완료 단계로 복귀한다.
- 상세정보의 일부 입력은 보관하되, 다음 버튼을 누르기 전에는 해당 단계를 완료로 처리하지 않는다.
- 후보 화면에 다시 들어갈 때 서버에서 후보 이미지 주소를 갱신하고 기존 선택을 복원한다.
- 임시 등록은 같은 기기, 같은 계정, 같은 API 환경에서 마지막 저장 후 7일 이내 복원한다. 앱 삭제나 데이터 삭제 후에는 복원하지 못한다.
- 등록 완료 또는 확인창의 그만두기로 임시 등록을 지운다. 그만두기는 이미 접수된 서버의 생성 연산을 중단하는 기능은 아니다.

## 알림 제약

현재 완료 알림은 앱이 서버 상태를 확인한 뒤 보내는 로컬 알림이다.

- 앱 안에서 다른 화면을 보고 있는 동안에는 상태를 확인하고 완료 알림을 보낼 수 있다.
- 다른 앱으로 이동하거나 앱을 종료하면 즉시 완료 알림을 받는 것은 보장하지 않는다. 앱이 다시 활성화되면 상태를 확인한다.
- 앱이 중단된 상태에서도 완료 시점에 알림을 보내려면 서버 푸시를 별도로 연결해야 한다.
- 알림 권한이 없거나 알림을 지워도 정원 카드와 하단 진행 알림으로 복귀할 수 있다.
- 이전 계정, 다른 작업, 이미 등록을 마친 작업의 알림은 열지 않는다.

## 기기 확인 순서

1. 사진을 보내 생성 요청이 접수되면 종 검색 중 상단 X로 나간다. 홈 하단 진행바와 정원 마지막 카드를 확인한다.
2. 정원 카드로 돌아가 종을 고른다. 위치만 선택하고 흙 메모를 일부 입력한 뒤 X로 나간다.
3. 앱을 종료하고 다시 연다. 카드로 돌아갔을 때 위치와 메모가 남고, 미입력 필수 항목이 있으면 다음 버튼이 비활성인지 확인한다.
4. 입력을 마치고 생성 대기 화면에서 나간다. 완료 알림을 바로 누르지 않고 기다렸다가 눌러 후보 3개가 표시되는지 확인한다.
5. 후보 하나를 선택하고 이름을 일부 입력한 뒤 나간다. 복귀하면 후보 이미지가 다시 조회되고 기존 선택과 입력한 이름이 유지되는지 확인한다.
6. 결과 화면의 다시 만들기를 누른다. 확인 후 재생성을 시작하면 이전 완료 표시가 남지 않고 새로운 진행률이 표시되는지 확인한다.
7. 진행 중 하단 알림의 X만 누른다. 등록이 삭제되지 않고 정원 카드가 남는지, 완료되면 하단 알림이 다시 나타나는지 확인한다.
8. 등록을 완료한다. 정원에 실제 식물이 표시되고 임시 카드와 하단 진행 알림이 사라지는지 확인한다.
9. 별도 등록에서 그만두기를 확인한다. 앱을 재시작해도 해당 임시 등록이 복원되지 않는지 확인한다.

## 화면 확인

- 작은 화면과 큰 글자 설정에서 하단 알림이 설정·잎 버튼 및 홈 인디케이터와 겹치지 않는지 확인한다.
- 하단 알림은 앱 배경색 기반 반투명 배경, 두 줄 제목, 가로 진행바, 한 줄 상태 메시지로 표시한다.
- 등록 화면 안에서는 같은 작업의 하단 알림을 숨긴다.
- 자동 테스트는 화면 콜백과 상태 전이를 검증한다. 실제 iOS 알림 전달, 스택 전환 및 화면 배치는 기기 확인이 필요하다.
