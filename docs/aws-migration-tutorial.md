# AWS 이전 실습 가이드

실행 절차를 [AWS 이전 작업 가이드](aws-team-handoff.md)에 통합.
기존 개요·실습·배포 문서의 중복을 줄이고, 현재 코드에 맞는 설정값과 담당 순서를 한 문서로 관리.

## 포함 범위

- 담당자별 준비물과 병렬 진행 순서
- EC2·RDS·S3·SQS·IAM 준비
- 학교 DB·이미지·Qdrant 백업과 복원
- AWS API와 학교 AI worker 설치·환경 설정
- Windows Tailscale에서 WSL 서비스 연결
- 모바일 실행, 통합 테스트, 오류 확인
- 운영 전환, 복구 기준, 완료 기록

실제 접속값·비밀값·실행 결과는 팀의 비공개 운영 문서에서 관리. 검수 완료 커밋 SHA 공유 후 배포 진행.
